What C turns into

Small pieces of C, each compiled with agbcc exactly as lodis-qol builds it, next to the asm it produces. Pick an instruction below to see every example that uses it, for example negs: "what produces this?"

Instruction
Conditions come out inverted

An if becomes "if NOT the condition, jump over the body".

lsrs vs asrs

After lsls #24/#16: lsrs is a u8/u16, asrs an s8/s16.

The jump tells the type

bgt/blt… signed; bhi/bcc… unsigned.

Registers

r0–r3 arguments and result; r4–r7, r8–sl survive calls.

Every listing is real output: agbcc -mthumb-interwork -O2 -fhex-asm -fprologue-bugfix, assembled and disassembled with arm-none-eabi-objdump (the same view scripts/ndiff.sh shows). Jump targets show as → N, the line they land on. Highlighted lines are the ones the example is about.
